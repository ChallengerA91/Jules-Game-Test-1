# Farming Tycoon RTS

A farming tycoon game where you compete against other AI-controlled farms.

## Mechanics
- Plant and harvest crops.
- Sell crops to the market.
- Prices fluctuate based on supply and demand.
- AI farms also plant and sell, affecting the market.

## How to run
1. Install dependencies: `npm install`
2. Run the game: `npm start`
3. Run tests: `npm test`
